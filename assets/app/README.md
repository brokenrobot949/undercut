# App icon

The home-screen icon: the anvil icon by Lorc (game-icons.net, CC BY 3.0, credited in `assets/icons/CREDITS.md`) on a dark tile.
`icon.svg` is the source. The PNGs (512, 192 and 180 for iPhone) were rendered from it with headless Edge.
The anvil sits inside the middle 60%, so phones that crop icons into circles or rounded squares keep all of it.
